Privacy Policy

KidsShorts uploader for the Tiny Smart Shorts YouTube channel. Effective 28 October 2026.

Who we are

Tiny Smart Shorts is a YouTube channel of short educational videos for young children, run by one independent creator. KidsShorts is a private desktop tool that the channel owner runs on their own computer to upload the channel's own videos. It has no other users, no website login and no app for the public.

Use of YouTube API Services

KidsShorts uses YouTube API Services to upload videos and captions to the Tiny Smart Shorts channel. Anyone using KidsShorts agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What information is accessed, collected and stored

  • Google sign-in token: when the channel owner signs in, Google issues an OAuth access token and refresh token. They are stored only on the owner's own computer and are used only to upload to the owner's own channel.
  • Own channel information: the tool reads the owner's channel name and ID to confirm it is uploading to the right channel.
  • Videos and their details: the tool sends the owner's own videos, titles, descriptions, tags and captions to YouTube.

KidsShorts does not access, collect or store any information about viewers, children, other YouTube users or anyone else's channel. It does not use analytics, advertising identifiers or tracking.

How the information is used and shared

The information above is used only to upload and schedule the channel's own videos. It is not sold, shared with third parties, or used for any other purpose. It is sent only to Google/YouTube through the YouTube API Services.

Cookies

KidsShorts is a desktop tool and does not place, read or store cookies or similar technologies on anyone's device. This website does not use cookies either.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page (Third-party apps with account access). Revoking access, or deleting the token file from the owner's computer, stops all API access immediately. No other copy of the data is kept.

Children's privacy

Every video on the channel is marked "made for kids" on YouTube, which turns off personalized ads, comments and other data collection on YouTube's side. KidsShorts itself never collects any information from or about children.

Changes

If this policy changes, the new version will be posted on this page with a new effective date.
